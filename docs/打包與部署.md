# 打包成 .exe 與在其他電腦使用

這份文件說明怎麼把 LiveSub 打包成 `LiveSub.exe`，帶到**沒有安裝 Python 的電腦**上使用。

---

## 1. 打包（在你自己的開發電腦上做）

### 需要
- 已經照 [使用說明書](使用說明書.md) 安裝過（專案裡有 `.venv`）
- 約 1 GB 硬碟空間，打包時間約 3～10 分鐘

### 指令

```powershell
cd C:\Users\<你的使用者名稱>\work\live-subtitle
powershell -ExecutionPolicy Bypass -File tests\build_exe\build_exe.ps1
```

完成後會產生：

| 檔案 | 說明 |
|---|---|
| `dist\LiveSub\` | 整個程式資料夾（`LiveSub.exe` 在裡面） |
| `dist\LiveSub.zip` | 上面資料夾的壓縮檔，**帶到其他電腦用這個** |

其他選項：

```powershell
# 保留黑色命令視窗（可以直接看到錯誤訊息，除錯用）
powershell -ExecutionPolicy Bypass -File tests\build_exe\build_exe.ps1 -Console
# 不要產生 zip
powershell -ExecutionPolicy Bypass -File tests\build_exe\build_exe.ps1 -NoZip
```

### 打包了什麼、沒打包什麼

| 有打包 | 沒有打包（不會外流） |
|---|---|
| Python 本身與所有套件 | 你的 `config.toml`（個人設定） |
| 程式碼 | 你的 API 金鑰 |
| `config.example.toml`、`glossary.example.csv`（範例） | 你的 `glossary.csv`（術語表） |
| `docs\` 說明文件 | `transcripts\` 逐字稿、`logs\`、`usage_ledger.json` |

> 術語表想一起帶過去的話，把你的 `glossary.csv` 手動複製到對方的 `LiveSub` 資料夾即可。

### 打包相關檔案

| 檔案 | 說明 |
|---|---|
| [`tests/build_exe/build_exe.ps1`](../tests/build_exe/build_exe.ps1) | 打包腳本：安裝 PyInstaller → 產生圖示 → 打包 → 複製範例與文件 → 壓縮 |
| [`tests/build_exe/livesub.spec`](../tests/build_exe/livesub.spec) | PyInstaller 設定：要打包哪些套件、資料檔、DLL，以及 exe 圖示 |

> 這兩個檔案放在 `tests/` 底下，但不是自動測試；pytest 只執行 `test_` 開頭的檔案，不會執行它們。

## 2. 在其他電腦使用

### 對方電腦需要
- Windows 10／11（64 位元）
- 網路（雲端辨識與翻譯）
- **不需要** Python、不需要安裝任何東西

### 步驟
1. 把 `LiveSub.zip` 複製過去（隨身碟、雲端硬碟都可以）
2. **解壓縮**到想放的位置，例如 `D:\LiveSub` 或「文件」裡
   > ⚠️ 不要直接在 zip 裡雙擊執行，一定要先解壓縮
3. 打開資料夾，雙擊 **`LiveSub.exe`**
4. 第一次執行，Windows 可能跳出「Windows 已保護您的電腦」（SmartScreen）：
   按「**其他資訊**」→「**仍要執行**」
   > 這是因為 exe 沒有數位簽章，不是病毒。防毒軟體偶爾也會誤判 PyInstaller 打包的程式，需要時請加入例外。
5. 設定視窗打開後：
   - 「**API 金鑰**」分頁：貼上對方自己的金鑰（金鑰存在對方電腦的 Windows 使用者設定，不在資料夾裡）
   - 「**服務與費用**」分頁：選語音辨識與翻譯服務
   - 「**逐字稿**」分頁：選逐字稿要存在哪裡（見下一節）
6. 按下方的「**建立桌面捷徑**」，之後從桌面的「即時字幕」開啟
7. 按「**開始字幕**」

### 逐字稿存在哪裡？

設定視窗「**逐字稿**」分頁可以選任何資料夾：

| 選擇 | 適合 |
|---|---|
| 預設（`LiveSub\transcripts`，和程式放一起） | 整個資料夾帶著走，逐字稿也一起帶走 |
| 「文件」裡的資料夾（按「瀏覽…」選） | 固定在這台電腦使用，和程式分開保存 |
| 隨身碟或公司共用資料夾 | 要交給別人或集中保存 |

每次按「開始字幕」都會在選的資料夾裡建立一個 `日期_時間` 子資料夾，裡面有 `subtitles.srt`、`transcript.txt`、`transcript.jsonl`。
按「開啟資料夾」可以直接打開。

> 選的資料夾之後不能用了（例如隨身碟拔掉），程式不會當掉，而是這次改存到預設位置，並在字幕上方提示實際存放位置。

### 程式放在「不能寫入」的地方時

如果把 `LiveSub` 資料夾放在 `C:\Program Files` 這類需要系統管理員權限的地方，
程式會自動把設定檔、log、用量紀錄、預設逐字稿改存到：

```
%APPDATA%\LiveSub
```

（在檔案總管網址列輸入 `%APPDATA%\LiveSub` 就能打開。）
建議直接放在 `D:\` 或「文件」裡，所有東西都在同一個資料夾，比較好找。

## 3. 更新到新版本

1. 在開發電腦重新執行 `build_exe.ps1`
2. 對方電腦：把新的 `LiveSub` 資料夾內容覆蓋舊的
   - `config.toml`、`glossary.csv`、`transcripts\` 不在新版的資料夾裡，所以**不會被覆蓋**
   - API 金鑰存在 Windows 設定裡，也不受影響

## 4. 常見問題

| 狀況 | 處理 |
|---|---|
| 雙擊 `LiveSub.exe` 沒反應 | 看看工作列或系統匣，設定視窗可能被擋住了；再看 `LiveSub\logs\livesub.log`（或 `%APPDATA%\LiveSub\logs`） |
| 跳出「Windows 已保護您的電腦」 | 「其他資訊」→「仍要執行」 |
| 防毒軟體刪掉了檔案 | 把 `LiveSub` 資料夾加入防毒軟體的例外，再重新解壓縮 |
| 想看詳細錯誤訊息 | 用 `-Console` 重新打包，執行時會有黑色視窗顯示 log |
| 搬動了 `LiveSub` 資料夾，捷徑失效 | 開啟 `LiveSub.exe`，在設定視窗按「建立桌面捷徑」 |
| 想用本機語音辨識（不上傳音訊） | 打包前在開發電腦安裝 `requirements-local-asr.txt`（或 GPU 版），打包時會自動包進去；模型第一次使用時下載到 `LiveSub\models` |
