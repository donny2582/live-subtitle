# LiveSub 即時字幕 使用說明書

LiveSub 會把電腦正在播放的聲音（Teams／Zoom／Google Meet 會議、YouTube、影片）
即時轉成**繁體中文字幕**，浮在所有視窗的最上層，並自動存成逐字稿與 SRT 字幕檔。

- 支援語言：英文、日文、韓文 → 繁體中文（台灣用語）
- 聲音來源：電腦播放的聲音、麥克風，或兩者同時
- 不需要虛擬音效線，也不需要顯示卡（雲端模式）

> 本說明書給「使用者」看，一步一步照著做即可。
> 進階調校與開發資訊請看專案根目錄的 [README.md](../README.md)。

## 1. 運作原理（30 秒看懂）

字幕分成兩個步驟，**兩步可以用不同公司的服務**：

```
電腦的聲音 ──► ① 語音辨識（聽寫成原文） ──► ② 翻譯（翻成中文） ──► 螢幕字幕
                 Groq / OpenAI / 本機           Claude / OpenAI / DeepL
```

| 步驟 | 可選服務 | 需要的金鑰 |
|---|---|---|
| ① 語音辨識 | **Groq**（推薦，最便宜）、OpenAI、本機 Whisper | `GROQ_API_KEY` 或 `OPENAI_API_KEY` |
| ② 翻譯 | **Claude Haiku 5.5**（推薦）、OpenAI、DeepL | `ANTHROPIC_API_KEY`、`OPENAI_API_KEY` 或 `DEEPL_API_KEY` |

> ⚠️ **Anthropic（Claude）沒有語音辨識功能**，只能負責第 ② 步翻譯。
> 第 ① 步一定要另外選 Groq、OpenAI 或本機模式。

**推薦組合**：Groq 辨識 ＋ Claude Haiku 5.5 翻譯 → 一場 2 小時會議約 0.15 美元以內。

## 2. 第一次安裝

### 2-1. 需要的東西

- Windows 10／11（64 位元）
- Python 3.11～3.14（在 PowerShell 輸入 `python --version` 確認）
- 網路連線

### 2-2. 下載程式

```powershell
cd C:\Users\<你的使用者名稱>\work
git clone https://github.com/donny2582/live-subtitle.git
cd live-subtitle
```

### 2-3. 安裝套件（擇一）

**方法 A：用安裝腳本（建議）**

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1
```

腳本會自動依序尋找 Python 3.12、3.13、3.14、3.11。電腦裡有好幾個版本、想指定其中一個時，可以加上 `-Python`：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1 -Python python
```

**方法 B：手動一行一行安裝**（腳本有問題時使用，結果完全相同）

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install --upgrade pip
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m pip install -e . --no-deps
copy config.example.toml config.toml
copy glossary.example.csv glossary.csv
```

看到 `Setup complete.` 或 `Successfully installed ...` 就代表成功。

方法 A 會順便在桌面建立「**即時字幕**」捷徑（藍底白色「字」圖示）。
用方法 B 手動安裝，或捷徑不見了，可以用這行重新建立：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\create_shortcut.ps1
```

### 2-4.（選用）本機語音辨識

不想用雲端辨識（例如會議內容不能外傳）時才需要：

```powershell
.venv\Scripts\python -m pip install -r requirements-local-asr.txt   # 一般電腦
.venv\Scripts\python -m pip install -r requirements-gpu.txt         # 有 NVIDIA 顯示卡
```

第一次啟動會下載約 1.6 GB 的模型。沒有 NVIDIA 顯示卡時會自動改用小模型，速度與準確度較差。

## 3. 申請 API 金鑰

只需要申請「你選的服務」的金鑰。推薦組合需要 **Groq ＋ Anthropic** 兩把。

### 3-1. Groq（語音辨識，推薦）

> ⚠️ **Groq ≠ Grok**！
> **Groq**（console.groq.com）是本程式要用的語音辨識服務，金鑰開頭是 **`gsk_`**。
> **Grok** 是 xAI（馬斯克的公司）的聊天機器人，金鑰開頭是 `xai-`，**本程式用不到**。
> 填錯會出現 `HTTP 401` 錯誤。

1. 打開 **console.groq.com**，註冊／登入（可用 Google 帳號）
2. 左側選 **API Keys** → **Create API Key**
3. 取個名字（例如 `livesub`），複製金鑰（`gsk_` 開頭）
4. ⚠️ 金鑰只顯示這一次，請先貼到設定視窗再關掉網頁

**費用**：有免費方案，**不用綁卡、不用儲值**。一般會議（2 小時約 600 句）免費額度就夠用。
超過免費上限時 log 會出現 `HTTP 429`，等一下就會恢復；要放寬上限可在 Billing 綁卡升級（事後依用量扣款）。

### 3-2. Anthropic（Claude 翻譯，推薦）

1. 打開 **console.anthropic.com**，註冊／登入
2. **Billing** 先儲值（預付制）
3. **API Keys** → **Create Key**，複製金鑰（`sk-ant-` 開頭）

### 3-3. OpenAI（選用：辨識或翻譯都可以）

1. 打開 **platform.openai.com**，註冊／登入
2. **Billing** 先儲值（**預付制**，最少約 5 美元）
3. **API keys** → **Create new secret key**，複製金鑰（`sk-` 開頭）

### 3-4. 該選 Groq 還是 OpenAI 做語音辨識？

| | **Groq** whisper-large-v3-turbo | **OpenAI** gpt-4o-mini-transcribe |
|---|---|---|
| 付費方式 | 有免費方案；付費為事後扣款 | 需先儲值 |
| 2 小時會議約 | 0.1 美元以下（免費額度內 0 元） | 0.25 美元 |
| 判斷語言 | ✅ 服務會回報是英／日／韓 | ❌ 程式只能看文字猜 |
| 日文漢字短句 | 判斷穩定 | 可能被誤判成中文 |

**建議**：先用 Groq。常遇到 `HTTP 429` 或覺得辨識不準，再換 OpenAI。
（價格以各家官網為準。）

## 4. 在設定視窗填入金鑰與選擇服務

**不需要打 `setx` 指令**，所有設定都可以在小工具視窗裡完成。

### 4-1. 開啟設定視窗

**雙擊桌面的「即時字幕」捷徑**，程式會先打開設定視窗。設定好之後按「**開始字幕**」就會開始，按「結束」則離開程式。

字幕開始後也能再改設定：**右鍵字幕** 或 **系統匣「字」圖示** →「設定…」。

### 4-2. 「API 金鑰」分頁

1. 找到對應欄位（例如 `GROQ_API_KEY`、`ANTHROPIC_API_KEY`）
2. 貼上金鑰 → 按「**儲存**」
3. 儲存後只會顯示頭尾幾個字（例如 `gsk_…a1b2`），方便確認是哪一把
4. **紅字**代表「目前選的服務需要這把金鑰，但還沒設定」

> 金鑰存在 Windows「使用者環境變數」（效果和 `setx` 一樣），**不會**寫進 `config.toml`，
> 不會不小心上傳到 GitHub。程式啟動時會直接讀取，存完即可使用。

### 4-3. 「服務與費用」分頁

| 欄位 | 推薦選擇 |
|---|---|
| 語音辨識 | 雲端 Groq whisper-large-v3-turbo（最便宜） |
| 翻譯 | Claude Haiku 5.5（推薦，便宜） |
| 每月最多 | 預設 5 美元，用完會自動暫停雲端請求 |

選好後視窗會顯示「2 小時會議約多少錢」。

### 4-4. 其他分頁

| 分頁 | 可以調整 |
|---|---|
| 音訊與斷句 | 聲音來源（見第 6 章）、停頓多久算一句、雜音過濾、會出現的語言 |
| 字幕外觀 | 字型、字級、同時顯示幾句、寬度、透明度、位置（存檔後立即套用） |

> 除了字幕外觀，其他設定存檔後需要**重新啟動**程式才會生效。

## 5. 啟動與日常使用

### 5-1. 啟動

1. 雙擊桌面的「**即時字幕**」捷徑
2. 設定視窗打開後，確認服務與金鑰都設好了（沒問題的話什麼都不用改）
3. 按「**開始字幕**」

如果選的服務需要的金鑰還沒填，按下「開始字幕」時會跳出提醒，並自動切到「API 金鑰」分頁。

程式同時只會開一個。字幕已經在執行時再雙擊捷徑，不會多開一份，而是把原本那個程式的設定視窗叫到最前面。

> 從捷徑啟動時不會出現黑色的命令視窗，錯誤訊息都會寫進 `logs\livesub.log`；
> 嚴重錯誤會另外跳出對話框提醒。

啟動後播放一段英／日／韓語影片，螢幕下方就會出現字幕：

```
Welcome to today's meeting.          ← 原文（小字）
歡迎參加今天的會議。                   ← 中文（大字）
```

### 5-2. 操作方式

| 動作 | 效果 |
|---|---|
| 左鍵拖曳字幕 | 移動位置 |
| Ctrl ＋ 滑鼠滾輪 | 調整字級 |
| 右鍵字幕／系統匣「字」圖示 | 開啟選單 |
| 左鍵點系統匣圖示 | 快速切換「點擊穿透」 |

### 5-3. 選單功能

| 選單項目 | 說明 |
|---|---|
| 暫停 | 暫停辨識與翻譯（不花錢） |
| 點擊穿透 | 滑鼠可以點到字幕後面的視窗 |
| 顯示原文 | 開關原文小字 |
| 字放大／字縮小 | 調整字級 |
| 重新連接音訊裝置 | **換耳機或喇叭後一定要按** |
| 開啟本次逐字稿資料夾 | 查看這次的逐字稿 |
| 設定… | 開啟設定視窗 |
| （最下方） | 本月雲端花費 |
| 結束 | 關閉程式 |

### 5-4. 逐字稿

每次啟動會在 `transcripts\日期_時間\` 建立一個資料夾：

| 檔案 | 用途 |
|---|---|
| `subtitles.srt` | 字幕檔，可搭配錄影檔使用 |
| `transcript.txt` | 易讀版逐字稿 |
| `transcript.jsonl` | 機器可讀，方便後續做摘要 |

### 5-5. 術語表

`glossary.csv` 可以固定專有名詞的譯法，每行一組「原文,固定譯法」：

```csv
source,target
section control,區間測速
```

可在設定視窗按「編輯術語表」修改。用 Excel 編輯時請「另存為 **CSV UTF-8**」。

## 6. 聲音來源：三種模式

在設定視窗「音訊與斷句」分頁 →「來源」選擇：

| 選項 | 收得到 | 適合 |
|---|---|---|
| **電腦播放的聲音**（預設） | 對方說話、影片聲音 | 看影片、聽別人簡報 |
| **麥克風** | 只有你自己說話 | 自己練習口說、現場演講 |
| **電腦播放的聲音＋麥克風** | 雙方都收，混在一起辨識 | 線上會議中，對方和自己都要翻譯 |

選「電腦播放的聲音＋麥克風」時，下方會多出「**麥克風裝置**」欄位，通常用「自動」即可。

> ⚠️ 使用「電腦播放的聲音＋麥克風」時**請戴耳機**。
> 沒戴耳機時，麥克風會把喇叭的聲音再收一次，同一句話會出現兩次字幕。

## 8. 常見問題與錯誤排除

所有錯誤都會寫進 `logs\livesub.log`，啟動的 PowerShell 視窗也會顯示。

### ❌ `py.exe : No suitable Python runtime found`（安裝時）

舊版安裝腳本的 bug：電腦沒有 Python 3.12 時，腳本會直接停止，不會繼續找其他版本。新版已修正，請先更新程式：

```powershell
git pull
```

還是不行的話，指定要用的 Python：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1 -Python python
```

或照 [2-3 方法 B](#2-3-安裝套件擇一) 手動安裝。

### ❌ `找不到環境變數 GROQ_API_KEY`（或其他金鑰）

還沒設定該服務的金鑰。到設定視窗「API 金鑰」分頁貼上並儲存，再重新啟動程式。

### 😶 雙擊捷徑後什麼都沒出現

1. 看看工作列或系統匣，設定視窗可能被其他視窗擋住了
2. 打開 `logs\livesub.log`，看最後幾行有沒有錯誤
3. 移動過專案資料夾或刪過 `.venv` 的話，捷徑會失效：重新執行 `setup.ps1`，或執行 `scripts\create_shortcut.ps1` 重建捷徑

### ❌ `API 金鑰無效或沒有權限（HTTP 401）`

金鑰被服務拒絕。依序檢查：

1. **是不是填錯公司的金鑰？** Groq 的金鑰開頭是 `gsk_`；`xai-` 開頭的是 Grok（xAI），不能用
2. 設定視窗「API 金鑰」分頁顯示的頭尾字元，是否和官網上的金鑰一致
3. 官網上這把金鑰是否已被刪除 → 不確定就建一把新的重新貼上
4. 以前用 `setx` 設過舊金鑰 → **關掉 PowerShell 開新的**再啟動

### ⚠️ `HTTP 429`（請求太頻繁）

碰到免費方案的使用上限，等幾分鐘會自動恢復。常發生的話可升級付費方案或改用 OpenAI。

### ⚠️ `辨識引擎 ... 不適合即時中間結果，只輸出定稿`

這是**正常訊息**，不是錯誤。雲端辨識只在每句講完後出字幕（約 1～2 秒延遲），以節省費用。

### 😶 完全沒有字幕

1. 確認聲音是從 **Windows 預設播放裝置** 出來的（Teams 可能另外指定了喇叭）
2. 換過耳機／喇叭 → 選單按「重新連接音訊裝置」
3. 列出所有裝置，在設定視窗「裝置」手動選擇：
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\run.ps1 -ListDevices
   ```
4. 確認設定視窗「會出現的語言」有勾到實際的語言

### 😵 字幕點不到、無法拖曳

可能開啟了「點擊穿透」，從系統匣圖示的選單關閉即可。

### 🔁 同一句話出現兩次

使用「電腦播放的聲音＋麥克風」模式但沒戴耳機。請戴耳機，或改回「電腦播放的聲音」。

### ✂️ 句子被切得太碎／字幕太慢

預設值偏向「快」：停頓 0.45 秒就算一句講完，一句最長 5 秒。字幕出現的順序是：
原文先出現，接著中文一邊翻譯一邊顯示，最後變成白色的定稿。

在設定視窗「音訊與斷句」分頁調整：

| 想要 | 調整 |
|---|---|
| 句子不要被切碎、翻譯更通順 | 「停頓多久算一句」調高到 600～800 毫秒；「一句最長」調高到 7～10 秒 |
| 更快出字幕 | 「停頓多久算一句」調低到 350～400 毫秒；「一句最長」調低到 4 秒 |
| 長句切開後，前後翻譯更連貫 | 「服務與費用」分頁的「參考前文」調高到 2～3 句 |

### 🔧 設定改壞了

刪掉 `config.toml`，下次啟動會自動從 `config.example.toml` 複製一份預設值。

## 9. 指令速查表

都在專案資料夾 `live-subtitle` 內執行：

平常**雙擊桌面捷徑**就好，下面的指令是給需要用命令列的情況：

| 要做什麼 | 指令 |
|---|---|
| 啟動（先開設定視窗） | `powershell -ExecutionPolicy Bypass -File scripts\run.ps1` |
| 跳過設定視窗，直接開始字幕 | `scripts\run.ps1 --skip-settings` |
| 只開設定視窗 | `powershell -ExecutionPolicy Bypass -File scripts\run.ps1 -Settings` |
| 重新建立桌面捷徑 | `powershell -ExecutionPolicy Bypass -File scripts\create_shortcut.ps1` |
| 列出音訊裝置 | `powershell -ExecutionPolicy Bypass -File scripts\run.ps1 -ListDevices` |
| 臨時改成雙方都收 | `scripts\run.ps1 --source both` |
| 臨時只要原文、不翻譯 | `scripts\run.ps1 --engine none` |
| 臨時改用 Claude 翻譯 | `scripts\run.ps1 --engine claude` |
| 記錄詳細延遲到 log | `scripts\run.ps1 --log-level DEBUG` |
| 更新程式 | `git pull` |
| 打包成 .exe（給沒有 Python 的電腦用，詳見 [打包與部署](打包與部署.md)） | `powershell -ExecutionPolicy Bypass -File tests\build_exe\build_exe.ps1` |
